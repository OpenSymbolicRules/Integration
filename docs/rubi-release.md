# Rubi 4.17.3.0 reference edition

Start with [the release manifest](../editions/rubi-4.17.3.0/rules/meta.json) for new OSR integration work. Its 198 files follow the loader of Albert D. Rich's final version, published posthumously on 18 December 2023. Enable elementary rules, disable step display, and preserve both the file and array order. The manifest contains **7,375 converted source entries**. A host must implement the predicates, optional patterns, variable binding and operational heads it uses. In particular, preserve the distribution and evaluation semantics of Rubi's `Star` even though its arithmetic result is a product. Source order alone also cannot reproduce every Wolfram downvalue priority. [Upstream release and paclet](https://github.com/RuleBasedIntegration/Rubi/releases/tag/4.17.3.0)

The loader, package metadata, utility file and all 198 loaded rule files agree byte for byte between the release Git tree and the paclet. The maintenance revision also declares 4.17.3.0. Eight subsequent commits changed upstream, including definite-integral checks and limit directions. A version string cannot distinguish the two. Do not add the two profile counts or transfer a proof by matching a bare ID. [Upstream revision comparison](https://github.com/RuleBasedIntegration/Rubi/compare/f7fa0fd7bfacd326bc9e125473c5bad41cfad4e4...61e9c18ea248061cd83c67882f7c91a73cef912d)

The pinned loader has 7,410 textual `Int` definitions. With step display disabled, it selects one of each of 22 pairs of alternatives. The release exports 7,375 rules. The 13 other selected integration definitions are transcribed in the [coverage ledger](../editions/rubi-4.17.3.0/coverage.json) with their original conditions, proposed order and divisor guards, and a link to the checked real interpretation. The remaining six non-rule blocks define five helper predicates and initialize the Gamma flag. See the [cell-by-cell review](derivative-cell-review.md). All 198 loaded files contain converted rules. Section 4.1.8 contains eight entries, including four repeated source definitions. Its substitutions use a fresh local factor on every invocation of `Module`. A consumer must preserve the local binding during recursive integration. Section 9.1 includes eight active source rules. Cells 2, 4 and 5 integrate weighted derivatives of positive integer order by parts. Cells 9 and 12 perform product and power-product substitutions. Cells 19–21 integrate first derivatives of products, quotients and logarithmic quotients. See the [function bindings and real-domain hypotheses](rubi-translation-proposal.md#real-proofs-for-the-three-first-derivative-rules). Coverage counts describe transcription. Rule applicability, mathematical validity and compiled Lean evidence must be evaluated independently. The release archive carries the [upstream MIT notice](../editions/rubi-4.17.3.0/LICENSE). See also [the source-profile and verification notes](source-edition.md).

## Reproduce the released edition

Use the repository's converter environment. The output directory must be new. The producer reads Git objects directly and works with any Rubi checkout containing the pinned commit. Pass the optional downloaded paclet to verify the archive digest and all 201 source blobs.

```sh
git submodule update --init vendor/Rubi
julia --project=converter -e 'using Pkg; Pkg.instantiate()'
python3 scripts/rubi_release.py vendor/Rubi /tmp/osr-rubi-release --paclet /path/to/Rubi-4.17.3.0.paclet
python3 scripts/check_expanded_profile.py /tmp/osr-rubi-release/rules editions/rubi-4.17.3.0/rules
cmp /tmp/osr-rubi-release/coverage.json editions/rubi-4.17.3.0/coverage.json
cmp /tmp/osr-rubi-release/errata.json editions/rubi-4.17.3.0/errata.json
cmp /tmp/osr-rubi-release/LICENSE editions/rubi-4.17.3.0/LICENSE
```

See [post-release CAS rules and regression cases](post-rubi.md) for additions with independent provenance.
